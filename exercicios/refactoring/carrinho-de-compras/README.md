## Exercícios -- _Refactoring_

Considere o código presente junto dessa pasta. Ele implementa um carrinho de
compras, com todos os seus testes escritos em JUnit4. Todos os testes estão
passando (barra verde). Todo o projeto tem suas dependências resolvidas através
do Maven (podem utilizar para baixar todas as dependências). 

Para esse exercício espera-se que o aluno seja capaz de analisar o código,
identificar os maus-cheiros existentes, analisar as operações de refatoração
aplicáveis e, dentre elas, escolher e implantar aquela que mais se enquadra no
contexto. 

Até o momento vimos as operações de Refatoração do Grupo 1 (Compondo métodos) e
do Grupo 2 (Movendo recursos entre os objetos). Os slides para esses
grupos de refatoração estão disponíveis no seguinte [link](https://docs.google.com/presentation/d/1o5MMlXjf3Pcn5pIqFUMYgnAwx0AN4i8c/edit?usp=sharing&ouid=112746484255766107555&rtpof=true&sd=true).
As refatorações também estão descritas no site [Refactoring
Guru](http://refactoring.guru).

### Enunciado

Considere as operações de refatoração `Extrair método`, `Extrair variável`,
`Dividir variável temporária`, `Mover método`, `Mover campo (atributo)`,
`Extrair Classe` e `Substituir método por objeto-método`. Para cada uma dessas
operações de refatoração, identifique qual mau-cheiro ela é indicada para ser
aplicada. Identifique no código da aplicação onde que ela é indicada e efetue
sua aplicação. A aplicação da refatoração pode ser manual ou automatizada, a
depender de sua disponibilidade na IDE que você utiliza para desenvolvimento.
